# Contributing to RentReserve

Thank you for your interest in contributing to RentReserve.

## Development Setup

1. Fork the repository
2. Clone your fork
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature`

## Code Standards

- TypeScript for all JavaScript code
- Rust idioms for Soroban contracts
- Follow existing code style
- Write meaningful commit messages

## Pull Request Process

1. Ensure all tests pass
2. Update documentation if needed
3. Submit PR with clear description

## Issue Guidelines

When creating issues, include:

- Problem description
- Goal
- Scope and non-goals
- Technical requirements
- Acceptance criteria
- Tests required
- Security considerations

## Smart Contract Contributions

Contract changes require:

- Unit tests for all state transitions
- Authorization verification
- Invariant checking
- Event emission verification

## Security

Never commit secrets, private keys, or sensitive data. Report security issues privately.
