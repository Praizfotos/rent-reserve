# Security Policy

## Experimental Software

RentReserve is experimental software. Do not use Mainnet funds with an unreleased deployment.

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it responsibly by contacting the maintainers directly. Do not create public issues for security vulnerabilities.

## Security Practices

- Never share secret keys
- Always verify network, contract address and transaction details before signing
- Use hardware wallets for significant transactions
- Review transaction details before signing

## Smart Contract Security

- All contract operations require proper authorization
- Financial invariants are enforced on-chain
- Events provide verifiable audit trail

## Regulatory Compliance

Production deployment requires appropriate regulatory and security review. This software does not constitute financial advice or licensed financial services.
