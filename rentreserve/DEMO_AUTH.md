# Demo Authentication

This RentReserve application uses a **demonstration authentication system** - no real Google account or setup required!

## How It Works

🎯 **Perfect for demos and presentations**
- Click any "Log in" or "Start preparing" button
- Click "Continue with Google (Demo)" on the signin page
- Instantly access the full application experience
- No Google OAuth setup, no credit cards, no configuration needed

## Demo Features

✅ **Complete authentication flow simulation**
- Realistic signin page with Google branding
- Loading states and smooth transitions
- User profile display in the app sidebar
- Proper logout functionality
- Route protection (try accessing `/app/dashboard` directly)

✅ **Persistent demo session**
- Your "login" persists across browser tabs
- Stays logged in until you manually sign out
- Clean session management with localStorage

✅ **No external dependencies**
- No Google Cloud Console setup required
- No environment variables needed
- No API keys or OAuth configuration
- Works immediately out of the box
